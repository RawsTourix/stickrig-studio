# 12. Обратная связь и рабочая область v0.2

> Статус: реализовано в ветке `feat/editor-workspace-v0.2`; ручная проверка жестов на Windows-тачпаде ещё требуется.

## Проблемы, замеченные при первом запуске

1. Двухпальцевый свайп по тачпаду масштабировал сцену вместо прокрутки.
2. Боковые панели имели жёсткую компоновку и не сохраняли раскладку.
3. Кадры располагались внизу и не показывали миниатюр.
4. Новый проект начинался с 12 пустых кадров; пользователь ожидает ровно один.
5. Недоставало библиотеки доступных элементов.

## Реализованные изменения

- **Навигация:** колесо мыши и двухпальцевый свайп прокручивают сцену; `Ctrl+колесо/свайп` масштабирует вокруг указателя, средняя кнопка мыши — перетаскивание. На некоторых моделях тачпад передаёт жесты нестандартно; понадобится ручная проверка.
- **Панели:** Frames, Elements, Inspector, Layers и Camera реализованы на `QDockWidget`. Их можно перемещать, изменять ширину/высоту, объединять вкладками, откреплять и скрывать. Скрытые возвращаются из меню **View**, исходный вид — **View → Reset workspace**.
- **Настройки проекта:** Qt-состояние панелей хранится в поле `workspace.dock_state` файла проекта в base64. Параметры записываются вместе с проектом при **Save**. Старые JSON без `workspace` загружаются с раскладкой по умолчанию.
- **Кадры:** вертикальная панель слева, превью каждого кадра, выбор нажатием, операции добавления/удаления рядом с предпросмотром и настройкой FPS.
- **Производительность:** миниатюра создаётся напрямую в низком разрешении (128 px по ширине), только для видимых элементов списка, с выдачей по одной на цикл Qt. Они пересоздаются только после изменений сцены/кадров, а не на каждом шаге воспроизведения.
- **Первый кадр:** новый проект начинается с `duration_frames = 1`; добавление явным нажатием. Старые проекты с 12/72 кадрами сохраняют свою длительность.
- **Библиотека:** нижняя панель Elements с базовыми моделями Stickman, Line, Rectangle, Ellipse. В будущем — пользовательские пресеты/пакеты.

## Что не входит в эту итерацию

- Произвольные пользовательские модели в библиотеке.
- Перетаскивание модели прямо из панели на сцену (пока выбирается инструмент, затем клик по сцене).
- Изменение порядка кадров drag-and-drop.
- Плавное изменение длительности поз независимо от числа кадров.
- Нативные жесты pinch-to-zoom на всех драйверах Windows. При необходимости их добавим после обратной связи.

## Проверка вручную

1. Открыть новый проект, увидеть **Frame 1**, без пустых дополнительных кадров.
2. Добавить стикмена на 1-й кадр, нажать **+ Copy next**, изменить позу, увидеть разные миниатюры.
3. Убедиться, что свайп перемещает сцену, `Ctrl+свайп` увеличивает/уменьшает.
4. Переместить/закрыть панель, вернуть через **View**, сохранить проект, открыть заново — панели восстановились.
5. Открыть старый проект: его кадры остались на своих местах.
6. Просмотреть анимацию — проигрываются только реально имеющиеся кадры с выбранным FPS.
7. Прокрутить десятки кадров в панели — миниатюры подгружаются по мере появления на экране.

При обнаружении проблем обновлять документацию по фактическому поведению, а не утверждать, что вся поддержка тачпадов гарантирована.
