# 03. Рабочие процессы и интерфейс

> Цель UX: сделать «добавил человечка → согнул руку → следующий кадр → просмотр» самым коротким путём к первой анимации.

## Общий каркас

Режимы переключаются в верхней части окна: **Конструктор / Анимация / Монтаж**. Это разные рабочие пространства **одного** проекта, а не три отдельных приложения.

Примерная компоновка анимационного режима (не окончательный макет):

```text
┌──────────────── Проект · Сохранение · Режимы · Экспорт ────────────────┐
│ Инструменты │              Рабочая сцена               │ Инспектор      │
│ выделения  │   · сетка (по желанию)                    │ объект/сустав  │
│ фигуры     │   ┌────────── камера ──────────────┐       │ цвет/толщина  │
│ персонажи  │   │      персонажи и окружение     │       │ слои          │
│ оружие     │   └────────────────────────────────┘       │ библиотека    │
│            │     масштаб UI / возврат к камере         │               │
├─────────────────────────────── Таймлайн ──────────────────────────────┤
│  ◀  ▶  FPS  │  1  2  3  4  5  6  ...  │ onion skin │ + кадр        │
└───────────────────────────────────────────────────────────────────────┘
```

Идея расположения инструментов может опираться на удобство редакторов уровней (в том числе Geometry Dash), но без копирования чужого интерфейса один в один.

## 1. Конструктор

Здесь создаются **повторно используемые** ресурсы.

- Примитивы: линия, круг, прямоугольник, многоугольник; затем пути, кривые Безье и кисть.
- Стиль: обводка, заливка, цвета, толщина, прозрачность.
- Действия: выбрать, переместить, повернуть, изменить размер, копировать, группировать, отразить, изменить порядок.
- Составные объекты: жёсткие сегменты, суставы, точки вращения, узлы прикрепления, ограничения.
- Персонажи: базовый rig, разные размеры/цвета/головы, свои скелеты в перспективе.
- Составное оружие: пары элементов на соединениях; редактор не обязан симулировать их движение.
- Библиотека: «сохранить как шаблон», импорт, экспорт, дублирование с новым ID и именем.

Пример: собрать катану из рукояти, гарды и клинка; указать `grip` как точку крепления к кисти.

## 2. Анимационная студия

Здесь создаётся содержимое сцен и поз.

**Быстрый сценарий**

1. Выбрать готового стикмена.
2. Щёлкнуть в сцену: создать экземпляр.
3. Перетащить сустав, сохраняя скелетные связи.
4. Нажать «Новый кадр» (копия текущей позы).
5. Снова изменить суставы.
6. Нажать «Воспроизвести» и при необходимости поправить кадры.

**Основные панели**

- Палитра объектов и инструментов.
- Холст: сцена, сетка, границы кадра, элементы за пределами камеры.
- Инспектор выбранного персонажа, предмета или камеры.
- Слои: фон, окружение, герои, передний план, эффекты; глаз/замок/порядок.
- Таймлайн: позиции ключевых поз, длительность, выделение диапазона, дублирование/вставка/удаление.
- Управление воспроизведением и onion skin.

**Система координат**

- Масштаб и панорамирование холста *не влияют* на выходное изображение.
- Камера имеет независимые координаты и масштаб, а на холсте видна её рамка.
- Кнопки «К камере» и «Показать всю сцену» решают разные задачи.
- Сетка имеет крупный шаг, подразделения и привязку; возможно временное свободное движение с точными дробными координатами.

**Onion skin**

Предыдущая/следующая позы показаны полупрозрачно; статичный фон по умолчанию **не подсвечивается как изменение**. Можно включать/выключать целые слои или конкретный объект. В дальнейшем — отдельные цвета для прошлого и будущего, количество соседних кадров и прозрачность.

## 3. Монтаж

Здесь **нет инструментов перемещения суставов и построения объектов**. Есть дорожки сцены/видео, музыки и звука; тримминг, перемещение клипов, маркеры событий, регулировка громкости и экспорт.

Клип сцены ссылается на её исходные данные, а не только на растровые кадры. Действие «Открыть сцену для правки» переводит в анимацию с сохранением положения монтажного курсора, после чего монтаж видит обновлённую версию.

## Неразрушающий подход

- Изменение одного экземпляра не должно автоматически переписывать шаблон в библиотеке.
- Редактирование исходного шаблона — отдельная явная команда с предупреждением о последствиях.
- Монтажная нарезка не удаляет исходные анимационные кадры.
- Undo/redo охватывает значимые изменения; дорогостоящие операции могут иметь контрольные точки.

## Предлагаемые горячие клавиши

| Действие | Кандидат |
| --- | --- |
| Сохранить | Ctrl+S |
| Отменить/повторить | Ctrl+Z / Ctrl+Y |
| Воспроизведение/пауза | Space |
| Предыдущий/следующий кадр | ← / → |
| Дублировать кадр | Ctrl+D в контексте таймлайна |
| Показать рамку камеры | команда/кнопка «К камере» |
| Временное панорамирование | пробел + перетаскивание, когда воспроизведение остановлено |

Это **предложения**, нуждающиеся в проверке конфликтов: например, Space одновременно может управлять воспроизведением и панорамированием. При реализации должна действовать однозначная контекстная схема, редактируемая по мере необходимости.

## Не перегружать UI

Расширенные режимы IK, кривые интерполяции, структура сложного rig и MCP-настройки скрывать до тех пор, пока пользователь не обращается к соответствующей задаче. Первое окно — не техническая панель управления движком.
