# 21. Восстановление длины конечности двойным кликом (v0.5.3)

> Реализовано по результатам ручного тестирования анимации. Интерфейс остаётся минималистичным; отдельной кнопки сброса больше нет.

## Управление

- Выбрать/редактировать персонажа в режиме `Select / Move`.
- **Двойной клик ЛКМ по управляющей точке** (локоть, кисть, колено, стопа и т. п.) восстанавливает исходную длину соответствующего сегмента до **100%**.
- Изменяется только `segment_scales[joint]`, то есть длина сегмента от родительской точки до выбранной. **Углы, изгибы и соседние сегменты не сбрасываются.** Положение дочерних суставов пересчитывается через FK естественным образом.
- Изменение регистрируется в истории Undo/Redo и в обычном сохранении проекта. Если длина уже 100%, никаких лишних записей истории не создаётся.
- Клик по пустой области, линии сегмента, оружию или обычному shape не является командой сброса. В режиме добавления нового объекта двойной клик также не сбрасывает чужие сегменты.

## Разрешение близких точек

Двойной клик ищет ближайшую реальную точку по текущему зуму без `Snap` и без смены цели при циклическом переборе совпадающих точек. Это необходимо, чтобы два быстрых клика по колену не приводили к неожиданному сбросу другого соседнего сустава.

При обычных одиночных кликах прежняя логика выбора ближайшей точки и возможности переключения практически совпадающих суставов сохраняется.

## Причина отказа от кнопки

Цель редактора — быстрое ручное создание множества последовательных поз. Перемещение курсора из холста в Inspector и обратно на каждом кадре требует лишних действий. Двойной клик делает восстановление исходной длины локальным жестом непосредственно на рисунке.

Числовое поле `Visible length` в Inspector **остаётся** для точной установки произвольного значения; удалена только специальная кнопка `Reset length to 100%`.

## Проверки

1. Укоротить голень через `Shift + drag`, сделать двойной клик по точке колена: исходная длина вернулась к 100%.
2. Убедиться, что противоположная нога и предыдущая настройка изгиба не изменились.
3. Проверить `Ctrl+Z` и `Ctrl+Y` после сброса.
4. Сделать двойной клик по пустому месту и по линии между суставами: сброс не выполняется.
5. Проверить две близкие точки при зуме 70%: двойной клик должен попадать в ближайшую, независимо от предыдущего выделения.

В CI используется прямое Qt-событие двойного клика через `QTest.mouseDClick` на viewport редактора.
