# 13. UX-итерация v0.3: холст, просмотр, кадры и локализация

> Статус: функциональность реализована в ветке `feat/scene-navigation-frames-v0.3`. Прежде чем считать поддержку завершённой, необходимо проверить ощущения от жестов и drag-and-drop в Windows.

## Запросы после тестирования v0.2

Пользователь попросил: сделать масштабно-зависимую чувствительность перемещения холста; перенести процент зума в нижний правый угол сцены; отделить воспроизведение в тонкий блок; добавить полупрозрачную модель под курсором перед размещением; расширить контекстные меню и быстрые действия кадров; разрешить перестановку кадров за отдельную область; подготовить RU/EN локализацию.

## Реализация

### Навигация

- При обычном свайпе двумя пальцами/вращении колеса рабочая сцена перемещается.
- При `Ctrl+колесо` масштабируется рабочий вид вокруг указателя; кнопки `− / % / +` размещены в нижнем правом углу холста.
- При изменении масштаба чувствительность панорамирования изменяется **плавно** по степенному закону: `clamp(zoom^(-0.22), 0.65, 1.8)`. Это не ступенчатый «множитель скорости» и не изменение камеры.
- Для мелких событий тачпада накопление дробной части прокрутки уменьшает дрожание.
- Средняя кнопка мыши по-прежнему позволяет перетаскивать холст.

### Предпросмотр перед размещением

- После выбора `Stickman`, `Line`, `Rectangle` или `Ellipse` на холсте отображается светло-синий полупрозрачный контур будущего элемента.
- Превью следует за указателем и учитывает режим Snap.
- Превью **не создаёт объект** в сцене, не меняет JSON и не попадает в рендер/экспорт.
- При рисовании фигуры её временный контур заменяет hover-превью.

### Панель Frames

- Сохранён вертикальный список миниатюр слева и отложенное создание только видимых превью.
- В строке кадра появились три нарисованные компактные кнопки: **скрыть/показать, дублировать, удалить**, а слева — **ручка для перетаскивания**.
- Правый клик **по кадру**: перейти, дублировать, скрыть/показать, сдвинуть вверх/вниз, удалить.
- Правый клик **по пустому месту**: добавить кадр после текущего, добавить в конец, показать все скрытые.
- Перестановка через ручку меняет **порядок видимых поз** и соответствующие индексы скрытых кадров, а не только порядок элементов списка.
- Для hold-анимации перенос пересобирает ключевые изменения в затронутом промежутке; остальные дорожки сохраняются в разреженном виде.
- Удаление кадра с ключом не должно изменять позы оставшихся кадров из-за наследования значений.

**Скрытый кадр** остаётся в проекте и доступен для редактирования, но пропускается при воспроизведении и экспорте MP4. Скрытое состояние не означает удаление: его можно отменить. Если скрыты все кадры, экспорт блокируется понятной ошибкой.

### Просмотр

- Воспроизведение, переходы по кадрам, номер кадра и FPS перемещены в отдельную тонкую нижнюю `QToolBar`.
- Предпросмотр и экспорт используют список **видимых** кадров по порядку; обычная ручная навигация позволяет переходить и на скрытые кадры.
- Экспорт PNG текущего кадра по-прежнему разрешён, даже если этот кадр скрыт из последовательности.

### Производительность

- Действия `Frames` рисует один `QStyledItemDelegate`, а не три `QPushButton` для каждого кадра.
- Миниатюры строятся непосредственно в 128px и только для видимых кадров с ограниченным кэшем.
- При смене текущего кадра список не пересоздаётся; флажки скрытия обновляются только по изменившимся индексам.
- Превью на холсте обновляет отдельный временный графический элемент вместо полного пересоздания сцены на каждом перемещении курсора.
- Большие проекты потребуют отдельного измерения скорости с тысячами кадров и примитивов.

## Локализация (проектная подготовка)

Добавлен модуль `stickrig.i18n` с каталогами сообщений на **английском и русском** и проверкой совпадения ключей.

- В текущей версии интерфейс **пока остаётся преимущественно английским**: полноценное переключение языков не заявлено.
- Новые строки постепенно выносятся из виджетов в каталог.
- При реализации переключения использовать единую языковую настройку приложения/рабочего пространства, не переводить значения ID/формата проекта.
- Целевые локали: `en` и `ru`; непереведённые строки должны возвращаться к английскому тексту.

## Проверить вручную на Windows

1. При уменьшении масштаба перемещаться по сцене легче, при увеличении — точнее; скорость изменяется без скачков.
2. Процент зума всегда остаётся в нижнем правом углу холста при изменении размеров док-панелей.
3. При выборе объекта курсор показывает полупрозрачный контур; движение курсора не создаёт новых объектов.
4. Контекстное меню на пустом месте списка кадров отличается от меню на существующем кадре.
5. Три быстрые кнопки работают, а захват только за левую ручку запускает перетаскивание.
6. После перестановки нескольких отличающихся кадров предпросмотр показывает новый порядок без потерь поз.
7. Скрытые кадры пропускаются в плеере и в MP4, но остаются в списке.
8. Сохранение/загрузка проекта, Undo/Redo и работа ИИ с JSON не повреждены.
